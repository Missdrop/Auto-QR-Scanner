# Third-party references

The background adapter uses the pinned [wechatauto-replica](https://github.com/fanyuantaier/wechatauto-replica) database reader and cache-only media decoder, licensed under Apache-2.0. The license is retained in `LICENSES/wechatauto-replica.txt`. `src/wechat/image_keys.py` extends its read-only configuration discovery for the tested client, using the documented configuration layout and image-key derivation from upstream `db.py` and `media.py`. A candidate must match the bound account and decrypt the target image's probe before it is cached with Windows DPAPI. No UI download or sending API is used by this adapter.

The PowerShell startup script downloads [uv](https://github.com/astral-sh/uv) from its official release, pinned by URL, size and SHA-256 in `scripts/uv.json`. Downloaded runtimes remain outside Git. The zstd override selects a release with Python 3.12 Windows wheels so setup does not require a native compiler.

The independent browser is an unbranded Chromium build from the [official Chromium snapshot archive](https://www.chromium.org/getting-involved/download-chromium/). Its revision, archive URL, size and official object MD5 metadata are pinned in `src/browser/chromium.json`. Installation verifies the archive, and startup verifies the installed executable's recorded SHA-256. Login launches it directly. Background QR processing uses [Playwright](https://github.com/microsoft/playwright-python), licensed under Apache-2.0, with this same executable and the application's dedicated persistent profile. Playwright connects through its private browser pipe; no debugging TCP port or browser extension is installed. Runtime files and their bundled licenses remain outside Git in `.runtimes`.

# Auto QR Scanner

自动处理微信群中新收到的签到二维码图片的实验项目。

## 目标

- 监听指定微信群的新图片消息。
- 识别人工拍摄屏幕的二维码，考虑倾斜、反光、摩尔纹和模糊。
- 对识别结果去重，并根据实际签到平台接入后续流程。

## 当前状态

项目处于方案调研阶段，尚未实现消息监听、图片识别或自动签到。

候选组件：

- [wxauto](https://github.com/cluic/wxauto)：Windows 微信界面自动化与图片获取。
- [ZXing-C++](https://github.com/zxing-cpp/zxing-cpp)：二维码检测与解码。

实际兼容性、拍屏识别率和处理延迟需要通过本机微信版本与真实样图验证。完成签到还取决于目标平台的登录状态和操作要求。

请勿向仓库提交聊天图片、个人信息、登录凭证或有效签到链接。
